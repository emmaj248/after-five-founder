# After Five Founder — visual implementation pack

## How to use
Copy this entire directory into your website repository at `design/after-five-target/`. Open Claude Code at the repository root and paste the contents of `01-master-prompt.md`. Do not send only the prose prompt. Claude needs the HTML, tokens, visual reference and QA protocol together.

## Authority order
1. Existing approved logo, authentic founder photo, published content, real tools and functional contracts are immutable.
2. `03-reference.html` defines layout, hierarchy, spacing and visual treatment. Its synthetic content is explicitly illustrative, not publication copy.
3. `02-design-tokens.css` defines proposed visual defaults; existing approved font files and logo take precedence.
4. `04-visual-qa.md` defines the acceptance gate.
5. `06-editorial-inspiration.png` is secondary inspiration for editorial organization only. Do not reproduce its generated portrait, generic photography, substitute logo or fictional articles.

The reference is a proposed direction, not a capture of the current website. No source repository or verified current browser screenshot was available when this pack was authored. Replace placeholders with real assets and validate against the current implementation before merging. No guarantee of perfect visual fidelity is possible without rendering and iterative review.

## Files
